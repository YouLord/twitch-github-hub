twitch × github

Четыре штуки для стримера
в одном репозитории

Живая статистика GitHub на стриме, автообновляемый README, бот, который пишет в чат о PR и релизах, и галерея клипов, которую собирают зрители. Ноль зависимостей, работает на бесплатных тарифах.

🖥️

B · Оверлей для OBS

Коммиты, ±строки, звёзды и последний коммит прямо в кадре. Добавь как Browser Source.
🔴

A · Live-бейдж в README

GitHub Action раз в 10 минут пишет в профиль статус эфира. Команда npm run update:readme.
🤖

C · Бот GitHub → чат

Вебхук присылает событие, бот пишет в чат. Команды !gh !stats !clip.
🎬

D · Галерея клипов

Зрители кидают !clip — клипы попадают на GitHub Pages.

Быстрый старт

1. Конфигcp .env.example .env
2. Запускnpm start
3. Демоnpm run demo
4. Галереяnpm run build:gallery
5. READMEnpm run update:readme
Без токенов всё работает в демо-режиме с мок-данными. Подключи TWITCH_CLIENT_ID, TWITCH_CLIENT_SECRET и GITHUB_REPO — цифры станут настоящими.
